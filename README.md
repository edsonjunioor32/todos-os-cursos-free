# Todos os Cursos Free

Catálogo independente de plataformas e materiais gratuitos para estudar, se qualificar e avançar profissionalmente.

O site é publicado pelo GitHub Pages e reúne links externos. As condições de gratuidade e de emissão de certificados podem variar conforme o curso, a turma e a plataforma. Consulte sempre a página original.

## Estrutura

- \`index.html\`: página principal do catálogo.
- \`styles.css\`: identidade visual e layout responsivo.
- \`theme.js\`: alternância entre tema claro e escuro.
- \`.github/workflows/pages.yml\`: publicação independente no GitHub Pages.
